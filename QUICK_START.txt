✅ Dependencies are already installed!

📋 NEXT STEPS:

1. CREATE ENVIRONMENT FILES
   -------------------------
   
   Create file: backend/.env
   Copy this content:
   
   PORT=5000
   DB_HOST=localhost
   DB_USER=root
   DB_PASSWORD=
   DB_NAME=mateshwari_exports
   JWT_SECRET=mateshwari_exports_super_secret_jwt_key_change_in_production_2024
   RAZORPAY_KEY_ID=your_razorpay_key_id
   RAZORPAY_KEY_SECRET=your_razorpay_key_secret
   CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name
   CLOUDINARY_API_KEY=your_cloudinary_api_key
   CLOUDINARY_API_SECRET=your_cloudinary_api_secret
   SHIPROCKET_EMAIL=your_shiprocket_email
   SHIPROCKET_PASSWORD=your_shiprocket_password
   NODE_ENV=development
   FRONTEND_URL=http://localhost:3000

   Create file: frontend/.env
   Copy this content:
   
   REACT_APP_API_URL=http://localhost:5000/api
   REACT_APP_RAZORPAY_KEY_ID=your_razorpay_key_id

2. SET UP DATABASE (Optional for now - app will work without it)
   -------------------------
   
   Open MySQL:
   mysql -u root -p
   
   Then run:
   CREATE DATABASE mateshwari_exports;
   USE mateshwari_exports;
   (Copy and paste contents of database/schema.sql)
   
   Or use:
   mysql -u root -p mateshwari_exports < database/schema.sql

3. START THE PROJECT
   ------------------
   
   Run this command:
   npm run dev
   
   This will start:
   - Frontend: http://localhost:3000
   - Backend:  http://localhost:5000

⚠️  IMPORTANT NOTES:
   - If you don't have MySQL password, leave DB_PASSWORD= empty
   - The app will work without database initially (with errors)
   - You can add Razorpay keys later for payment features
   - For development, placeholder values work fine

🚀 The servers are starting in the background!
   Check your terminal for any errors.
